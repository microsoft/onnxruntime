# JS execution provider (JSEP) — deprecated

This directory is the native half of **JSEP**, the JavaScript/TypeScript WebGPU path in `onnxruntime-web`. It is
**deprecated** and will be removed. The replacement is the native WebGPU execution provider in
[`onnxruntime/core/providers/webgpu/`](../webgpu).

**Bug fixes and security fixes only.** New operators, new features and performance work belong in the WebGPU EP.

See [docs/JSEP_Deprecation.md](../../../../docs/JSEP_Deprecation.md) for more details.

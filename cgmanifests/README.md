# CGManifest Files
This directory contains CGManifest (cgmanifest.json) files.
See [here](https://docs.opensource.microsoft.com/tools/cg/cgmanifest.html) for details.

WebGPU plugin packaging generates and scans a manifest from the fetched Dawn dependencies instead of maintaining
a separate copy of their pins. See [webgpu/README.md](webgpu/README.md) for its inputs, scope, and local usage.

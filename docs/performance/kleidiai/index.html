Arm® KleidiAI™ software compatibility in ONNX Runtime

This page outlines support details for the Arm KleidiAI software micro-kernel library. Micro-kernels are integrated into ONNX Runtime via Microsoft Linear Algebra Subprograms (MLAS) to support CPU-Based inference acceleration on Arm-Based CPUs.
